Fine Art Printing

Implementation Plan — New Dedicated Page for Earl's Picture Framing

Background

The "Fine Art Printing" service card on the homepage currently links to bespoke-framing.html. This plan creates a dedicated page where customers can upload an image, choose a print paper/finish, optionally add a frame and mount, preview the result, and check out — all within the Dark Luxe Atelier aesthetic.

Inspiration drawn from EasyFrame's Print & Frame configurator.

Decisions Requiring Your Input

⚠ Reuse existing data?
Should this page reuse the existing frame/mount/glass data (data/frames.json, data/pricing.json) from Frame My Photo? This keeps pricing consistent. The plan assumes yes.
⚠ Default to "Print Only"?
EasyFrame defaults to "Print & Frame". I propose defaulting to Print Only with a clear toggle to add framing — making this page feel distinct from "Frame My Photo".
⚠ Canvas Stretch?
Should stretched canvas be a paper/output option within this page, or a separate service? I propose including it as a 5th paper type.
